# Клавіатурні перегони для 2–3 класів

Клавіатурний тренажер для початкової школи: учень друкує текст і змагається з роботом. Це спрощена версія гри [«Клавіатурні перегони»](https://cikavo.me/labs/typing-race/) з [Лабораторії](https://cikavo.me/labs/), зроблена з дозволу її автора. Оформлення й правила гри ті самі, змінено складність.

Грати: https://cyrilreyda.github.io/typing-race-kids/

## Що змінено порівняно з оригіналом

- Роботи повільніші: 12–40 знаків/хв для автівок і 12–25 у змаганнях (в оригіналі 35–125).
- Робот рушає на 2,5 с пізніше. Поки учень друкує, робот, що вирвався вперед, непомітно пригальмовує, тож гонка йде впритул. Якщо учень зупинився або друкує дуже повільно, робот може виграти.
- Коли робот фінішує першим, заїзд не обривається: учень дописує текст до кінця.
- Тексти коротші, а замість речень на трасах «Пустеля» й «Арктика» — фрази малими літерами без розділових знаків, тож Shift не потрібен.
- М'якші вимоги до точності: у змаганнях від 70–80%, золота медаль від 90%, срібна від 80%.
- «Формула 1» та «Слалом знаків» з'являються лише після перемоги зі швидкістю від 45 знаків/хв і точністю від 90%. У цих змаганнях робот не пригальмовує.
- Прогрес зберігається окремо від оригінальної гри (ключ `typing-race-kids-v1` у `localStorage`).

<details><summary>Де це в коді</summary>

Гра — один файл `index.html`, без сервера й збирання. Швидкості роботів — `CAR_CPM` і `cpm` у `COMPS`; підтримка початківців — `ASSIST`; поріг для прихованих змагань — `PRO_CPM`; тексти — `TEXTS` і `makeText`. Перший коміт репозиторію — незмінена копія оригіналу, тож `git diff` від нього показує всі зміни.

## Запуск

Відкрити `index.html` у браузері. Для локальної перевірки:

```powershell
python -m http.server 8766
```
